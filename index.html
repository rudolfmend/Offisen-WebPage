How Offisen works

From a familiar task to a reusable sequence in three steps, with no programming.

1

Record the task

Select REC and perform the routine in your desktop application as you normally would.

2

Edit and save the sequence

Give it a clear name, and correct text or waits if something needs to change.

3

Prepare and play it again

Return the target application to the starting state and select PLAY. Repeat it as many times as you choose.

Example: one optional step

You sometimes keep a notes application open, and sometimes not.

1

Main steps run

The main sequence fills in a form in your accounting application.

2

Offisen checks one window

If the right notes window is open, the attached sequence adds a note. If that window is not open, the attached sequence is skipped.

3

Main steps continue

The main sequence goes back to the accounting application and finishes its work.

A missing window is a normal skip. It is different when several windows fit, when the check itself fails, or when the window closes during the attached sequence: Offisen then stops the run instead of guessing. The check covers only whether that window is open, so Offisen does not evaluate other conditions or adapt to changes in an application.

You stay in control of playback

Pause, resume or stop

Pause a run, resume it when you are ready, or stop it whenever plans change.

Check the results

Run History shows which runs succeeded, failed or were stopped, so you know where to look.

Target safety checks

Offisen checks its target windows and stops when it cannot identify one safely, to avoid sending input to the wrong place. Some steps may already have run by then.

Watch the first run

Observe the first run of every new or edited sequence, and test it with data that is safe to change.

Subscription

Offisen is free to download, but it is not a permanently free app. Recording and playback require an active monthly subscription. Without one, you can still view your saved sequences.

Free first month

Try Offisen free for one month through Microsoft Store, when the offer is available for your account. The Store button may say “Buy”.

Then monthly

After the free month, the subscription renews automatically. Microsoft Store shows the price for your region before you confirm.

Cancel any time

Cancel in your Microsoft account (opens in new tab). If you cancel before the free month ends, you won't be charged.
