OFS-1809

Recorded target could not be resolved

Offisen could not safely identify the window this sequence was recorded against, so playback was stopped before input could be sent to the wrong place.

What this means

The intended window may be closed or may have changed. The recorded target information may also be missing or incomplete.

This error belongs to target identification during playback. It is a blocking safety error: Offisen does not continue when it cannot resolve the target with enough confidence.

What to do

  1. Open the application and window that the sequence was originally recorded against.
  2. Return the application to the expected starting screen.
  3. Select the sequence and try playback again.
  4. If the application or its window has permanently changed, record the sequence again.

Example

If a sequence was recorded in a browser window and that window is now closed, renamed, or displaying a different application state, Offisen may be unable to resolve it safely. Open the intended browser window, return to the expected page, and retry.

If the problem continues

Record the same task again and test the new sequence. If a newly recorded sequence also produces OFS-1809, keep the diagnostic report and contact info@offisen.app.

Include the error code, correlation ID, timestamp, target application, and a short description of what happened. Review the report before sharing it and remove anything you do not want to send.
