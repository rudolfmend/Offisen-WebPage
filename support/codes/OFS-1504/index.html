OFS-1504

Current text cursor position could not be used

“Use current text cursor position” is enabled, but Offisen could not confirm a valid editable field in the application currently in focus.

What this means

This mode intentionally uses the field that is focused at playback time instead of activating the originally recorded field. Offisen found no recognizable editable target and therefore sent no text or key input.

What to do

  1. Open the application where the text should be entered.
  2. Click directly inside the intended editable text field so the caret is visible.
  3. Resume or retry playback.
  4. If the problem continues, turn off “Use current text cursor position” for this recording and use its recorded target instead.

Why this can happen

  • No text field was focused when playback reached the step.
  • The focused control is not recognized as editable.
  • Focus moved back to Offisen or to a non-editable part of the target application.
  • The target application exposes insufficient focus information.

Example

If a browser page is in the foreground but the user has clicked the page background rather than an input box, there is no safe current caret target. Offisen blocks typing.

If the problem continues

If a visible, editable field is focused and OFS-1504 still appears, include the report and identify the target application and control type without sharing the text you intended to enter.

Include the error code, correlation ID, timestamp, Offisen version, target application when relevant, and a short description of what happened. Review the report before sharing it and remove anything you do not want to send.
