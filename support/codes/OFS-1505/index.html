OFS-1505

Application could not be safely opened or activated

Playback stopped at a step that opens or switches to an application because Offisen could not verify exactly one window of the intended application.

What this means

Offisen could not confirm that the right application window was opened or brought to the front. It stopped playback at this step, so the remaining actions were not run against an unverified window.

The report may include ApplicationLaunchPerformed. If it says False, Offisen did not launch the application during that attempt; do not assume the application was opened by the failed step.

What to do

  1. Make sure the intended application is installed and can be opened normally.
  2. Check that it is not running as administrator while Offisen is running without administrator rights.
  3. Leave exactly one window of that application open, or close it fully before retrying.
  4. Run the sequence again. If the step already opened the application, do not open it a second time manually.

Why this can happen

  • The application is unavailable or cannot be opened.
  • Several windows of the same application are open and Offisen cannot identify one unambiguously.
  • The application runs with higher permissions than Offisen.
  • The application did not expose a window that Offisen could safely verify at this step.

Example

A sequence tries to switch to a browser that has several windows open. If Offisen cannot confirm which window is the intended one, it stops before running the following actions. Close the extra windows or start with the browser fully closed, then retry.

If the problem continues

Copy the diagnostic report and describe which application should have opened or become active, and whether it had any windows open before playback.

Include the code, correlation ID, timestamp, Offisen version, and a short description of what happened. Review the report before sharing it and remove anything you do not want to send.
