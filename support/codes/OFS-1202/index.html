OFS-1202

FilterKeys may affect keyboard input

Windows FilterKeys is enabled. Short or rapidly repeated key presses may be delayed or ignored during recording or playback.

What this means

FilterKeys is a Windows accessibility feature that can change how short, repeated, or held key presses are accepted. Offisen does not change this setting; it asks you to decide whether to continue with the current configuration.

What to do

  1. Decide whether FilterKeys is enabled intentionally.
  2. If you rely on FilterKeys, continue and carefully verify the recorded or played keyboard result.
  3. Otherwise, turn FilterKeys off in Windows Settings under Accessibility → Keyboard.
  4. Retry the recording or playback and compare the result.

Why this can happen

  • FilterKeys was enabled in Windows accessibility settings.
  • A keyboard shortcut enabled FilterKeys unintentionally.
  • An organization or accessibility profile configured key delay, repeat, or bounce behavior.

Example

A very short key press may be ignored when FilterKeys is configured to reject brief input. A recorded sequence can then differ from the action you performed even though the keyboard itself is working.

If the problem continues

If keyboard behavior still differs after FilterKeys is disabled, keep the support report and note whether the issue occurred during recording, playback, or both.

Include the error code, correlation ID, timestamp, Offisen version, target application when relevant, and a short description of what happened. Review the report before sharing it and remove anything you do not want to send.
