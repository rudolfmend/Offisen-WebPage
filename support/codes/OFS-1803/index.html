OFS-1803

Pointer could not be positioned safely

The resolved pointer position was outside the available desktop or Windows could not place the pointer at the exact target. No mouse button input was sent.

What this means

Offisen calculated a screen position for a recorded pointer action, but that position was not safe in the current desktop layout. It blocks the mouse button action to prevent an unintended click.

What to do

  1. Check that every monitor used during recording is connected and arranged as expected.
  2. Confirm the target window is visible and not minimized.
  3. Close or reconfigure software that restricts pointer movement, including some remote-desktop or accessibility tools.
  4. Bring the target application to the foreground and retry playback.
  5. If the display layout changed permanently, record the workflow again.

Why this can happen

  • A monitor was disconnected, rearranged, or changed resolution.
  • The calculated point lies outside the current virtual desktop.
  • Windows could not move the pointer to the requested coordinate.
  • Remote-desktop, virtualization, or accessibility software constrained the pointer.

Example

A workflow recorded on a second monitor can point outside the desktop after that monitor is disconnected. Offisen refuses to click at a substituted location.

If the problem continues

If the monitor layout has not changed and the error repeats, include the report and describe the monitor arrangement and any remote-desktop or pointer-management software in use.

Include the error code, correlation ID, timestamp, Offisen version, target application when relevant, and a short description of what happened. Review the report before sharing it and remove anything you do not want to send.
