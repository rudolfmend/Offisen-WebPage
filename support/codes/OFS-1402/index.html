OFS-1402

Pointer position could not be converted

Offisen could not safely translate the recorded pointer position into a valid position for the current target, DPI, or monitor layout. Playback was stopped and no pointer input was sent.

What this means

A recorded pointer action must be converted from its saved position into current screen coordinates. Offisen could not complete that conversion with a valid target size or position.

This is a blocking safety error. Offisen stops before the pointer action instead of risking a click in the wrong place.

What to do

  1. Make sure the intended application and target window are open and fully loaded.
  2. Return the application to the screen and state used when the sequence was recorded.
  3. Make sure the target window is not minimized or hidden, and that the expected button, field, or other control is available.
  4. If monitors, display scaling, or screen arrangement have changed, restore the original display setup when possible.
  5. Try playback again.
  6. If the application or display setup has changed permanently, record the sequence again in the current environment.

Why this can happen

  • The target window or control is no longer providing a valid size or position.
  • The application is not on the expected screen, or its interface has changed.
  • A monitor was disconnected, added, or rearranged.
  • Windows display scaling or the target window placement changed after recording.

The code can appear even when the recorded and current DPI values shown in a report are the same. Invalid target geometry alone is enough to make a pointer conversion unsafe.

Example

A sequence contains a click at a position relative to a particular button. During playback, the button cannot provide a valid current width, height, or screen position. Offisen cannot determine where that saved point belongs, so it blocks the click.

If the problem continues

Record the same task again in the current window and monitor setup, then test the new sequence. If a newly recorded sequence also produces OFS-1402, keep the diagnostic report and contact info@offisen.app.

The report is classified as safe support context. It may include the target process name, window handle, DPI, display dimensions, and coordinate details. It does not include recorded text, document content, clipboard data, or screenshots.

Include the error code, correlation ID, timestamp, target application, display configuration, and a short description of what happened. Review the report before sharing it and remove anything you do not want to send.
