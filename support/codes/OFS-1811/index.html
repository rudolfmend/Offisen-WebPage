OFS-1811

Windows system action was not recorded

Offisen did not record a click on a Windows system surface, such as a taskbar window preview. The rest of the recording can continue.

What this means

The click was on a Windows system surface outside the target application. Offisen skipped that individual click, so the recording can continue, but the skipped action will not play back later.

What to do

  1. Continue recording if you do not need the skipped click in the sequence.
  2. If you need to work in another window, switch to it another way before recording the actions you want to play back.
  3. Record those actions inside the target application window.
  4. Before playback, check that any window you switched to manually is ready if the sequence depends on it.

Why this can happen

A taskbar window preview or another adjacent Windows system surface can appear while switching windows. Such a surface is different from the application window you intend to automate. Offisen reports this warning when it skips a click there.

Example

You click a window preview above the taskbar while recording. Offisen shows OFS-1811 and omits that preview click. You can continue recording actions inside the selected application, but playback will not repeat the preview click.

If the warning appears unexpectedly

If a normal click inside an application is skipped and reported as a Windows system action, copy the diagnostic report and describe where you clicked.

Include the code, correlation ID, timestamp, Offisen version, and a short description of what happened. Review the report before sharing it and remove anything you do not want to send.
