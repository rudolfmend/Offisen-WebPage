OFS-1502

Automatic recovery could not be verified

A command failed and its one automatic retry either failed again or could only be confirmed against a different target window.

What this means

Offisen rechecked the target and retried the failed command once. It still could not confirm a trustworthy result, so it stopped instead of continuing after an uncertain recovery.

What to do

  1. Make sure the target application is open, visible, unobstructed, and in a stable state.
  2. Close unexpected dialogs, popups, and notifications.
  3. Return the application to the expected screen.
  4. Return the application to a safe starting state and retry playback.
  5. If the same command fails repeatedly, record that part of the workflow again.

Why this can happen

  • The command failed again on its single automatic retry.
  • A dialog or another window became the target during recovery.
  • The target application changed state between the original attempt and the retry.

Example

A click opens a dialog at the same moment that Offisen retries the action. Even if the retry reports success, Offisen will reject it when the live target is no longer the original window.

If the problem continues

The report can identify whether the retry failed or the target changed during recovery. Include it with a description of any dialog or popup that appeared.

Include the error code, correlation ID, timestamp, Offisen version, target application when relevant, and a short description of what happened. Review the report before sharing it and remove anything you do not want to send.
