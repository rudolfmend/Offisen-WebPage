OFS-1701

Global keyboard shortcut could not be activated

Neither the primary nor fallback global keyboard shortcut could be registered. The corresponding shortcut action is unavailable.

What this means

Another application or Windows component may already own the same key combination. Offisen continues to work, but you must use its visible controls for the affected action. Holding Esc for emergency stop remains available during playback.

What to do

  1. Use the controls in the Offisen window for the affected action.
  2. Check whether another running application uses the same shortcut combinations.
  3. Close or reconfigure the conflicting application when practical.
  4. Restart Offisen so it can try registering the shortcuts again.

Why this can happen

  • Another application registered the same global shortcut.
  • A keyboard utility, overlay, accessibility tool, or system component reserved the combination.
  • Windows rejected both the primary and fallback registration attempts.

Example

A communication or keyboard utility may already use the playback shortcut globally. Offisen cannot take it over, but playback can still be paused or resumed from the app window.

If the problem continues

If both shortcut attempts fail after other keyboard utilities are closed, send the support report. It contains the attempted combinations and Windows error values.

Include the error code, correlation ID, timestamp, Offisen version, target application when relevant, and a short description of what happened. Review the report before sharing it and remove anything you do not want to send.
