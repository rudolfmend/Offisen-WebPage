OFS-1810

Taskbar action was not recorded

Offisen does not record clicks on the Windows taskbar. The click was skipped and the rest of the recording can continue.

What this means

Taskbar windows are transient system surfaces and do not provide a reliable playback target. Offisen omits the individual click rather than saving a step that would later fail or activate the wrong item.

What to do

  1. Continue the current recording; the skipped taskbar click did not add a step.
  2. Keep the target application open before playback.
  3. Record actions inside the target application window.
  4. If the taskbar click was needed to open an application, prepare that application before starting the sequence instead.

Why this can happen

  • The click landed on the primary Windows taskbar.
  • The click landed on a secondary-monitor taskbar.
  • The taskbar was used to open, switch, minimize, or restore an application during recording.

Example

Clicking a taskbar icon to restore a browser is not added to the sequence. Open and prepare the browser first, then record the actions inside it.

If the problem continues

This warning normally needs no support action. If an ordinary click inside an application is incorrectly classified as the taskbar, copy the report and describe where you clicked.

Include the error code, correlation ID, timestamp, Offisen version, target application when relevant, and a short description of what happened. Review the report before sharing it and remove anything you do not want to send.
