OFS-1904

Input processing hit an internal error

Processing a global keyboard or mouse event failed unexpectedly. Offisen stopped the active operation because input events could otherwise be lost or recorded incorrectly.

What this means

An exception occurred inside the low-level input-processing path during recording or playback. Offisen contains the failure and stops the affected operation rather than continue with incomplete input handling.

What to do

  1. Try the recording or playback again once.
  2. If the error returns, stop using the affected sequence for important data until the cause is understood.
  3. Copy the support report and restart Offisen.
  4. Review the report before sharing it, then contact support.

Why this can happen

  • A keyboard or mouse event triggered an unexpected internal exception.
  • A component involved in low-level input processing failed.
  • A repeatable interaction exposed an unhandled input-processing condition.

Example

A particular mouse or keyboard event causes an internal input subscriber to throw. Offisen catches the failure, stops the active operation, and records the technical exception information for diagnosis.

If the problem continues

The report may contain an exception type and exception message. Exception messages can occasionally include local paths, usernames, or other machine-specific details. Review the report carefully and share it only with your consent.

Include the error code, correlation ID, timestamp, Offisen version, and what you were doing immediately before the error.
