OFS-1301

Input method (IME) text may not be captured correctly

The active layout may use an input method editor. Offisen records physical keystrokes, so the composed text may not match what you typed.

What this means

An IME can turn a series of keystrokes and candidate selections into different final characters. Offisen currently records the physical keys rather than the final IME composition, so the saved TypeText step needs to be checked.

What to do

  1. Finish the recording and review every affected TypeText step.
  2. Compare the recorded text with the characters that were actually entered.
  3. Correct the saved text manually if it differs.
  4. When practical, record the affected fields using a non-IME keyboard layout.

Why this can happen

  • A Chinese, Japanese, or Korean keyboard layout is active.
  • Text was composed through an IME candidate window.
  • The active layout is IME-capable even if the particular field used direct alphanumeric input.

Example

Typing a phonetic sequence and selecting a Japanese kanji candidate produces characters that are different from the physical keys. Offisen warns that the recorded step may contain the key sequence rather than the selected result.

If the problem continues

This warning describes a current limitation. If you need help, state the language and keyboard layout used, but do not send confidential composed text.

Include the error code, correlation ID, timestamp, Offisen version, target application when relevant, and a short description of what happened. Review the report before sharing it and remove anything you do not want to send.
