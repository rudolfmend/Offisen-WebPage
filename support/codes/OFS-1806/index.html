OFS-1806

Multiple matching target windows found

Offisen found more than one equally plausible target window and stopped before activating one or sending input.

What this means

Several live windows match the recorded window identity closely enough that Offisen cannot safely choose between them. Selecting whichever window Windows lists first would be a guess.

What to do

  1. Check which windows are open before starting again. Identify the ones belonging to the recorded target application.
  2. Close the extra matching window or change its title or state so the intended target is unique.
  3. Bring the intended window to the expected starting screen.
  4. Retry playback.
  5. If the workflow routinely uses several identical windows, record it in a state that gives the intended window a distinct identity.

Why this can happen

  • Two documents or browser windows have the same or equally matching title.
  • Several windows of the same application expose indistinguishable recorded identity.
  • Element probing could not resolve a single safe winner among the matching windows.

Example

Two browser windows display the same page title. Both match the recorded target equally well, so Offisen refuses to choose one and risk entering data into the wrong window.

During an attached sequence check Coming in version 1.0.9

The same protection applies when playback reaches an attached sequence. If its window cannot be identified uniquely, the attached sequence neither runs nor counts as skipped. The whole run ends, even when Stop sequence when a command fails is off.

The duplicate window may belong to the attached sequence, not to the main sequence.

“Any window of the same application” is not a random choice

With Any window of the same application, one open window of that application is enough, whatever its title. With several open windows, the recorded title decides. If none of them or more than one has that title, Offisen shows this code. It never picks a window at random or chooses the most recently used one.

Before starting again, keep only one window of that application open, or keep open the one window with the recorded title.

If the problem continues

If only one matching window appears visible, copy the report and note whether hidden dialogs, secondary windows, or multiple browser windows were open. The report contains counts and technical scores, not window titles.

Include the error code, correlation ID, timestamp, Offisen version, target application when relevant, and a short description of what happened. Review the report before sharing it and remove anything you do not want to send.
