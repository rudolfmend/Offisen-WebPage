OFS-9001

Offisen hit an unexpected internal error

An unhandled internal error occurred. Offisen stopped active recording or playback to avoid continuing in an unsafe state.

What this means

No more specific diagnostic guard classified the failure. This is a fatal catch-all error, so Offisen stops ongoing automation and may require a restart.

What to do

  1. Copy the support report before restarting Offisen.
  2. Review the report and remove anything you do not want to share.
  3. Restart Offisen using the dialog action when available, or close and reopen it manually.
  4. Check whether the same action causes the error again.
  5. If it repeats, contact support with the report and a short description of what happened immediately before the failure.

Why this can happen

  • An unexpected exception reached a global application error handler.
  • A background task failed without a more specific diagnostic classification.
  • The application encountered an internal state it could not continue from safely.

Example

An unexpected exception occurs during playback and no specialized guard recognizes it. Offisen stops playback, preserves a bounded technical summary, and asks you to restart rather than continue in an uncertain state.

If the problem continues

The report may contain the exception type, message, and stack trace. These details can include local paths, usernames, or incidental machine-specific information. Review the report carefully and share it only with your consent.

Include the error code, correlation ID, timestamp, Offisen version, and what you were doing immediately before the error.
