OFS-1103

Keyboard layout could not be identified

Offisen could not match the current dynamic Windows keyboard layout to a supported layout map. Recording can continue, but some special keys may be captured incorrectly.

What this means

Windows supplied a dynamically substituted keyboard layout identifier that Offisen does not currently recognize. Ordinary input may still work, but special, punctuation, or OEM keys can be mapped differently from what was intended.

What to do

  1. Note which keyboard layout is currently selected in Windows.
  2. If possible, switch to a supported standard installed layout and record the affected steps again.
  3. Review the recorded TypeText and keyboard steps, especially punctuation and special keys.
  4. If the layout must remain active, copy the support report so the layout can be evaluated for future support.

Why this can happen

  • Windows is using a dynamically substituted layout handle.
  • An IME, custom layout, or third-party keyboard layout is active.
  • The installed layout is not yet represented in Offisen’s supported layout map.

Example

A custom or substituted keyboard layout may use the same physical key differently from a standard layout. Offisen warns so you can verify the resulting recorded key before relying on the sequence.

If the problem continues

If a key was recorded incorrectly, include the warning report, the Windows layout name, and the specific key that differed. Do not include passwords or sensitive text.

Include the error code, correlation ID, timestamp, Offisen version, target application when relevant, and a short description of what happened. Review the report before sharing it and remove anything you do not want to send.
