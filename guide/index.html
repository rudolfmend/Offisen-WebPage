What Offisen does

Offisen helps you repeat routine work in Windows desktop applications. You perform a task while Offisen records the interaction, save the result as a sequence, and run that sequence again later.

You do not need to write a script. Offisen works with application windows and controls such as buttons, input fields, and dialogs.

Start with a small, predictable task. A short routine with clear steps is the easiest way to create your first successful automation.

Before you start

  • Open the application in which you want to record the task.
  • Prepare safe sample data when the task can change, submit, send, or delete information.
  • Place the target application in the state from which you normally begin the routine.
  • Close unrelated windows if they could be mistaken for the intended target.

Create your first automation

  1. Start recording. Select REC in Offisen or press F7.
  2. Perform the task. Work in the target application as you normally would. Keep the first recording short and deliberate.
  3. Stop recording. Select STOP or press F8 when the routine is complete.
  4. Name and save the sequence. Use a name that describes the result, such as “Export weekly report”. Save your sequences before closing Offisen.
  5. Return to the starting state. Prepare the target application as it was before recording.
  6. Run the sequence. Select the saved sequence and choose PLAY. Watch the first run and confirm that it produces the expected result.

Working with sequences

A sequence is a saved set of recorded actions. Saved sequences remain available after Offisen is restarted.

Keep sequences easy to recognize

  • Use a name based on the task or result.
  • Keep separate sequences for routines that start from different screens or applications.
  • Test a sequence again after the target application receives a significant update.
  • Use File → Open sequences folder when you need direct access to your sequence files.

You can select, rename, duplicate, delete, and move sequences in the main window. Review the selected sequence before changing its playback options.

Playback and repeat

Select the sequence you want to run before pressing PLAY. Offisen takes a snapshot of the selected playback settings when the run begins, so later changes apply to the next run.

Repeat options

  • Finite repeat: enter how many times the sequence should run.
  • Infinite repeat: choose the infinity option to continue until you stop playback.

Start condition

If Run only if target is ready is enabled, Offisen waits up to the selected number of seconds for the intended target. Playback does not begin if the target cannot be resolved safely.

Stop on error

Enable Stop on error when playback should end instead of continuing after a command fails.

Pause, resume, and stop

You can pause a running sequence, resume it when ready, or stop it completely. After stopping, prepare the target application again before starting a new run.

Compact mode

Compact mode keeps the essential recording and playback controls in a smaller window. The current sequence must be selected before playback can start. Repeat information is shown as a count such as 3× or as ∞.

Use the compact-view shortcut to move between the main and compact windows without interrupting your workflow.

Using Offisen safely

  • Observe the first playback of every new or changed sequence.
  • Test with non-critical data before using a sequence on important records.
  • Make sure the intended application and window are open before playback.
  • Do not continue when Offisen reports that it cannot identify the target safely.
  • Use pause or stop whenever the target application is no longer in the expected state.

Offisen blocks playback when it cannot safely resolve the recorded target. This is designed to prevent input from being sent to the wrong place.

Troubleshooting

The Play button is unavailable

Make sure a sequence is selected. In compact mode, playback also requires a valid selected sequence.

The sequence does not start

Open the intended target application and return it to the expected starting screen. If a start condition is enabled, check its waiting time and try again.

Playback stops with a diagnostic code

Use the support address shown by Offisen. Current help pages include:

  • OFS-1402: pointer position could not be converted
  • OFS-1809: recorded target could not be resolved

A previously working sequence no longer works

Check whether the target application, window title, starting screen, or workflow has changed. If the change is permanent, record the sequence again from the new starting state.

You need more help

Keep the diagnostic report and its correlation ID. Contact info@offisen.app and describe what you expected, what happened, and whether the issue can be repeated.
