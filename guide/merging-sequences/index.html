Merge sequences

Combine saved sequences into one new sequence that always runs them in order.

When to merge

Merge sequences when the same routines should always run one after another. The result is a new file; the original sequences stay unchanged.

Create a merged sequence

  1. Choose Tools → Merge sequences..., or right-click a sequence and choose Merge with....
  2. Under Saved sequences, find a sequence and select Add. Add at least two. The same sequence can be added more than once.
  3. Under Merge order, move or remove entries until the order is right.
  4. Enter the Name of the new sequence.
  5. Keep or turn off Wait between sequences. It is on by default, for 1 second, and accepts 0.1 to 600 seconds.
  6. Resolve anything listed under Playback settings that differ and Problems that prevent creating.
  7. Select Create.

The new sequence appears in the main list. Each source becomes a part named after that source. A source that already has parts keeps them. If a source changed after it was checked, Offisen repeats the check and asks you to review the result and select Create again.

You can create the sequence only while nothing is being recorded or played. The manual time of the sources is not carried over.

Settings of the new sequence

Playback settings

When the sources differ in Stop sequence when a command fails, Run only if target is ready or the wait time for the target, choose one value. It applies to the whole new sequence.

Text insertion for each part

Each part keeps the text insertion of the sequence it comes from. To change one part, select Change beside it. To use one value everywhere, turn on Use the same setting for all parts. Offisen still applies the setting to each part separately, so Current at start uses the current cursor for the first text block of each part. See Text insertion.

Windows needed at the start

Playback looks for the listed windows before the first step, including windows of later sequences. They must already be open when the new sequence starts, and the wait between sequences does not change this. The list is a cautious estimate.

Merging or attaching

Merging and attaching both copy steps, but they answer different questions.

MergeAttach with a condition
ResultA new sequence fileA copy inside the sequence you are editing
Does it always run?Yes, every part in orderOnly if its window is open when playback reaches it
Missing windowStops the run or prevents its start, according to the safety checksA missing window skips the copy
Windows at the startChecked before the first step, with the exceptions Offisen listsThe copy's windows are not checked before the start

Limits

  • Older versions of Offisen will not show a sequence that needs text insertion by parts. Offisen tells you when this applies.
  • Offisen cannot create the sequence if a source file is missing, unreadable or empty, or if its window roles are damaged. Remove that source from the order.
  • Extra data stored for a whole source file is not carried over. Offisen lists this under Information.
  • A sequence that contains an attached sequence cannot be merged.
