Text insertion

Choose a mode

Use Recorded when the text belongs in the same field every time. Use a current-cursor mode when the same text should go into whichever field you are working in, such as a template inserted into different documents.

ModeShown in summaries asWhat it does
RecordedAs recordedTypes into the recorded window and field. This is the default.
Current at startCurrent cursor for the first blockAt most the first text block goes to the current cursor. Later blocks use their recorded place.
Always currentCurrent cursor for every blockText blocks that start with a click into a field go to the current cursor.

Select the mode under Text insertion in the main window. Coming in version 1.0.9 You can also select Change in the Sequence Editor, or choose the mode while editing text there.

What counts as a text block

A block starts with a click recorded in a text field, directly followed by typing or by keys and then typing. In a current-cursor block, Offisen skips that click so it does not move your cursor. The keys and text that follow go to the current field until a different kind of step appears.

Text without a click before it never uses the current cursor. If you began typing during recording without clicking first, those steps use their recorded place. Waits and key presses alone are not text blocks.

Examples

In each example, “current” means the current cursor and “recorded” means the recorded place.

Type “one”, click field B, type “two”Everything is recorded, because the first text block has no click.“one”: recorded. Click B is skipped, “two”: current.

With Recorded, all of these steps run as recorded.

When Offisen chooses the field

Offisen does not pick one field for the whole run, and it does not capture the cursor when a part begins. It checks when playback reaches each step that uses the current cursor:

At that momentResult
Another application is in the foreground with a text field activeThe text goes into that field.
Offisen itself is in the foreground, for example after you selected PLAYOffisen checks and reactivates the field it remembered when the run started.
Another application is in the foreground without an editable fieldPlayback stops with OFS-1504. Offisen does not fall back to the remembered field.

Offisen remembers one field per run, before the first step. If it shows a target confirmation before the run, it keeps the field from before that confirmation. If a different window is active when the first step needs the cursor, playback stops with OFS-1504.

Try it

  1. Click into the field where the text should go.
  2. Start the sequence. PLAY works, because Offisen returns to the remembered field.
  3. Leave that field active until the text has been typed.

The text appears at your cursor, not in the field used during recording.

Sequences with parts

A merged sequence can use a different mode for each part. Each part is judged on its own:

  • In a Current at start part, the first text block of that part can use the current cursor. A part that opens with text without a click plays as recorded, and the next part is still judged separately.
  • A click at the end of one part is never joined with text at the start of the next part.
  • The wait between merged sequences does not count as a text block.

In a later part, the current field is whatever is active when that part reaches its text. That is often where the previous part finished, not where the cursor was when the whole sequence started.

In the main window, Use for all parts changes every part and saves the sequence right away.

After an attached sequence Coming in version 1.0.9

An attached sequence always inserts its own text as recorded and can move the foreground to its window.

  • If the attached sequence ran: the next current-cursor text goes back to the field remembered at the start of the run, not into the attached sequence's window. That is not necessarily the field used most recently.
  • If that field cannot be restored: for example because it was closed, playback stops with OFS-1504 and nothing is typed elsewhere.
  • If the attached sequence was skipped: nothing changes, and the current cursor is checked as usual.

An attached sequence also separates text blocks. A click before it is never joined with typing after it, even when it is skipped. Current at start still means only the first text block of the main sequence or part.

When it stops

Offisen sends text only after confirming an editable field. If it cannot, it stops with OFS-1504; earlier steps of the run may already have typed text. Applications that report little about their fields can trigger this even though a field looks active. In that case, use Recorded.
