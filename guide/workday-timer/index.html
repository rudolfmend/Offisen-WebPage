What it is for

The Workday & Timer window has two independent reminders: a daily alarm and a countdown. Neither affects recording or playback.

Open the window

In version 1.0.8.0, select the timer icon in the main window.

Coming in version 1.0.9 The icon is removed. Choose Tools → Workday & Timer instead, or select an active status button. If the window is already open, Offisen brings it forward.

Workday end alarm

  1. Turn on Enable workday end alarm.
  2. Set the time under End at. The default is 17:00.

Next shows when the alarm will notify you. If today's time has already passed, the next alarm is tomorrow. The alarm repeats every day, including weekends, until you turn it off.

Countdown

  1. Enter Hours, Minutes and Seconds. The shortest countdown is 6 seconds.
  2. Select Start.
ControlResult
PauseHolds the remaining time. The pending notification is cancelled.
ResumeContinues from the remaining time and schedules the notification again.
ResetEnds the countdown without a notification and returns it to Idle.

A running countdown continues by real time. If you close Offisen, it keeps counting; time spent closed does not reduce a paused countdown. When it reaches zero, Status shows Completed.

Status on the main page Coming in version 1.0.9

While something is active, the main page shows a short status button. Selecting it opens the Workday & Timer window; it does not change the alarm or countdown.

If both are active, both buttons appear. When nothing is active, the row disappears without leaving empty space.

When notifications arrive

Offisen schedules a Windows notification reading It's time to end the workday. or Countdown finished. Once scheduled, Windows delivers it even if Offisen is closed. This notification is the only alert; Offisen does not show a separate message or play its own sound.

For a notification to be scheduled:

  • Offisen must run as the installed app from Microsoft Store. Windows does not offer scheduled notifications to a build without an app package.
  • Offisen must not run as administrator.

If these conditions are not met, the timer still works but no notification appears, and Offisen does not warn you about it.

The daily alarm is scheduled 30 days ahead. Offisen extends this when it starts and during a daily rollover while it is open, so open it at least once within that time. Windows notification settings, such as Do Not Disturb, can also hide notifications. Change them in Windows.
