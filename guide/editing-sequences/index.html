What the editor is for

Use the Sequence Editor to fix typed text, adjust waits, add a short recording or remove steps. Your changes stay in the editor until you save them.

Coming in version 1.0.9 Move up and Move down, changing Text insertion in the editor and attached sequences. Everything else on this page is available in 1.0.8.0.

Open the editor

  1. In the main window, right-click the sequence.
  2. Choose Edit....

The Sequence Editor window opens with the steps of that sequence.

Steps, groups and recorded commands

One action you performed can be saved as several recorded commands. The editor combines commands that belong together into one card, so you work with the action instead of each command.

CardWhat it contains
A single stepOne command, such as Click, Press a key or Wait
Text entry: click and typingClicks into a field with the keys and text that follow them
Repeated blockThe steps of a recorded loop

Select Show all on a group to see its individual commands, and Show less to fold them again. Delete and move always apply to the whole card. For example, a click into a text field is deleted together with its typing.

Change text and waits

  1. Select Edit text or Edit wait on the step.
  2. Enter the new text, or the length of the wait in seconds.
  3. Select Apply.

The card shows the new value and the editor reports Unsaved changes.

Text cannot be empty. If nothing should be typed, delete the step. A wait can last up to 600 seconds. Key presses cannot be changed; delete the step and insert a new recording instead.

Insert a wait or a recording

Insert a wait

Select Insert wait on a card, enter the length and select Apply. The wait is added after that card.

Insert a recording

  1. Select Insert recording on a card, or Insert recording at the start above the steps.
  2. Perform the new steps in the target application.
  3. Select Stop recording in the editor, or stop recording as usual.

The new steps appear in the chosen place. If you close the editor during this recording, the recording is saved as a new sequence instead. If nothing was recorded, nothing is inserted.

The windows used by a new recording are checked before the sequence starts, so they must already be open when you run it.

Delete and move

Delete

Select Delete step or Delete group. The last remaining card cannot be deleted, because a sequence needs at least one step. Offisen asks for confirmation when the deletion changes which windows are checked before the run starts, for example when you delete a step that starts an application.

Move Coming in version 1.0.9

Select Move up or Move down to swap a card with its neighbour. Dragging is not available.

  • The button is unavailable when the move would join steps that do not belong together, such as text moved directly after a click into another field.
  • The editor warns you if the move changes which windows are checked before the run starts, or which text block uses the current text cursor.

Sequences with parts

A merged sequence is divided into parts, shown as Part 1: name. Inserted steps belong to the part where you insert them. Part headers do not move, and a card cannot move into another part.

Undo, save and close

CommandResult
UndoReverses the last change. Select it again to go further back. The editor has no Redo.
SaveWrites the changes to this sequence and reports Saved.
Save as new...Creates another sequence under a new name and leaves this file unchanged.
CloseWith unsaved changes, asks whether to Save, select Don't save to discard them, or cancel and keep editing.

You can save only while nothing is being recorded or played. If the file changed or disappeared after the editor opened, Save is turned off so that the other change is not overwritten. Use Save as new..., or close without saving.

What saving changes

  • Manual time: saving changed steps clears the recorded manual time used to estimate time saved. To get a new estimate, record the sequence again.
  • Step numbers: steps are numbered again after edits.
  • Target check exceptions: an exception belongs to one specific step. It ends if that step changes or gets a different number, so check Target check exceptions after editing.
  • Text insertion: if an edit changes which text block uses the current cursor, the editor shows a notice. Review the steps before saving. See Text insertion.

After saving, watch the next run to confirm that the sequence still does what you expect.

Coming in version 1.0.9 Changing only Text insertion does not change the steps, so it keeps their numbers and the manual time.
