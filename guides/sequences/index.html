What your file keeps

A sequence is a saved set of actions, such as clicks, typing and keyboard shortcuts. Offisen stores it in an .acseq file so you can use the same workflow again without recording it from scratch.

The last successfully saved version keeps:

  • The sequence name, description and steps in their saved order.
  • The recorded text, keys, values and other settings held by those steps.
  • Available information that helps Offisen find the target window and controls again.
  • The sequence’s chosen text-cursor mode.

Save your changes before you close Offisen

Changes are available next time only if they have been saved successfully. Seeing a sequence in the editor does not by itself confirm that its latest changes are on disk.

Prepare your workspace

Open the application and the document, sheet or tab that the sequence needs. Put them in the starting state used when recording, including any required dialog, selected field and scroll position.

A saved sequence does not restore an application session, sign you in or recover an unsaved document. Keep the intended window ready, and avoid leaving several indistinguishable copies of it open.

Check repeats after reopening Offisen

A new Offisen session starts with 1 repeat and infinite playback off. These controls are separate from the saved steps. Check them before pressing Play.

Run a saved sequence

  1. Save the sequence you want to keep

    After recording or editing, give the sequence a recognisable name and use Save All. Check that saving completes successfully.

  2. Reopen and prepare the target application

    After a restart, open the right application and document. Restore the required starting state and wait until the controls you need are ready.

  3. Select the saved sequence

    Choose it from the sequence list, or use Open to load its .acseq file. Check the name and saved steps.

  4. Check the cursor and choose one repeat

    If the sequence is configured to use your current text cursor, place it in the correct editable field or document. For the first check, select 1 repeat and turn infinite playback off.

  5. Press Play and check the result

    Watch the first run. Use Stop if the workflow targets the wrong place or behaves unexpectedly. Check what has already happened before trying again: another run may repeat completed actions.

Where will text be entered?

The saved text-cursor mode affects where text-entry parts of the sequence run. With recorded targeting, Offisen uses the recorded target and caret-placement instructions. A mode that uses the current cursor instead expects you to prepare the live text-entry destination.

If text appears in the wrong place, stop playback and check both the active document and the sequence’s cursor setting. Reopening a sequence does not restore a live cursor position from an earlier session.

When something goes wrong

The saved sequence is missing or will not open

Locate the .acseq file and check that it is available on this computer. If it is in a synced folder, let the download or sync finish. If the file is damaged, use a working copy or record the workflow again.

The target application or control cannot be found

Open the correct application, document and dialog, then wait until they are ready. Check whether the application’s title, language or layout has changed since recording.

OFS-1806: Offisen cannot choose a target window

More than one window may match the saved information. Save any work in those windows, close the unnecessary copies and try again with one clear target.

OFS-1402: Offisen cannot safely determine a click position

Restore the window’s previous size and proportions, and check for changes to monitors or display scaling. This can happen even when the DPI value has not changed. If the problem continues in your new layout, record the workflow again in that layout.

Text or a click goes to the wrong place

Press Stop. Check the document, sheet or tab, scroll position and text-cursor mode. Finding the right application window alone does not confirm that the content inside it is in the right state.

The first attempt stops, but a later attempt works

The target may not have been ready, but this alone does not establish the cause. Check the reported error, wait for the intended view to finish opening and restore the starting state before trying again.

When to check the sequence again

Repeat the one-run check after an application update, a change of interface language, a different layout or a move to another computer. An older recording may need to be replaced if the file format or target application has changed.

Successful reuse after restarting the target application has been verified in a test scenario. That result does not guarantee the same outcome in every application or on another PC. Keep a copy of a working sequence before changing it.

Need help?

Email info@offisen.app with your Offisen version, the application you are automating, the failing step and the exact error message. Mention what you restarted and what changed before the problem began.

Before sharing an .acseq file, check the text and values recorded in it.
